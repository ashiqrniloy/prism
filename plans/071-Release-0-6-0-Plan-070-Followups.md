# Release 0.6.0 — Plan 070 Follow-ups And Node 22 Floor

## Objectives

- Close every Further Action recorded by `plans/070-Release-0-5-7-Review-Remediation.md` (11 entries) as an executable task in this plan, so the list stops being prose that decays.
- Close the six items this plan recorded **while executing** Tasks 5-9 (three retired-gate/test-truth gaps, an operator-dependent secret scan, an LSP test race, a blocked-gate convention, and the coverage-summary blind spot) as Tasks 10-15, before the cut rather than after it — a follow-up list is only honest if it is drained before the release it feeds.
- Publish **Prism 0.6.0** as the release that carries plan 070's remediation content plus the support-matrix change those follow-ups justify (Node `>=20` → `>=22`).
- Supersede the unpublished 0.5.7 cut: 0.5.7 was cut in the working tree but never committed, tagged, or published (`node scripts/release.mjs check --lockstep --version 0.5.7` reports all ten packages `available`), so 0.6.0 is the first published release carrying that content — one cut, one changelog heading, one literal sweep.
- Remove the two release-blocking false negatives found in plan 070: the load-sensitive root-import startup ceiling and the `sandbox-browser.yml` job that references retired packages.
- Make the next release cut mechanical: one `currentVersion()` source for version literals and a gate that names any stale site, including the escaped-regex forms a plain `grep 0.5.6` sweep misses.
- Turn review-level typing debt (`style/noNonNullAssertion`, 2009 sites repo-wide) into a measured, monotonically shrinking budget instead of a number in a comment.

**Scope note.** This plan covers the Further Actions of plan 070 only. Open Further Actions in plans 067, 068, and 069 (`--wiki-root` defaults, host wiring examples for `extractDocument`/`fetchUrl`, `runObscuraCli` helper, fat-page changelog stripping, plan-069 triage list) are deliberately **not** included — they are not release-blocking for 0.6.0 and each carries its own demand gate. Also out of scope: the retired-gate items already recorded by plans 057/069 (they are audit evidence, not CI); Task 5 touches only the three retired gaps plan 070 measured, and Tasks 10-12 close the remaining retired-gate and test-truth gaps found while running it.
