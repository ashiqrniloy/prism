# Release 0.2.5 — Maintainability and Bounded Performance

Roadmap phase: `roadmap.md` § **0.2.5 — Maintainability and bounded performance**.
Baseline: `@arnilo/prism` **0.2.4** (plan 024 complete; 50-package publish graph = root + 49 workspace — 14 provider + 9 `prism-*` + 26 capability; `npm test` exit 0 — 3567 tests / 3534 pass / 33 protected-live skips / 0 fail; `security:threat-suites` 50/50; `test:postgres` 91/91; core coverage **90.53% lines / 84.20% branches / 90.54% functions** (gate 60/70/75); `scripts/phase24-baseline.json.exitGate.green: true`; `release:gate` 0.2.4 / 50 packages / 0 errors / 0 breaking deltas; Node 20 packed imports 24/24; `npm audit` 0; Biome 0 diagnostics; 43 code packages pin exact `@arnilo/prism: 0.2.4` peers; the 12-item mandatory 0.2.x regression matrix is closed across 0.2.0–0.2.3 — no 0.2.5-specific matrix item).
Target: `@arnilo/prism` **0.2.5**. Internal-only refactoring and bounded-performance work: split remaining god-modules along cohesive state-machine boundaries behind preserved public barrels; deduplicate proven PostgreSQL/SQLite persistence mechanics into the existing `session-store-codecs` package; replace the remaining quadratic `Buffer.concat` accumulators with chunk-array/bounded-stream processing; finish confirmed dead-code removal (stale `agent-session` imports/constants, `cache-telemetry` locals, `skill-load` map/scans, reviewed dead exports); and close low-coverage core behavior with focused runnable regressions. **No public runtime contract change is planned; no published package export is added or removed; no package is added to or removed from the publish graph; no new runtime dependency is introduced.** All changes preserve the existing compat baseline (zero breaking deltas) and the dependency-free core.

Scope items (mapped one-to-one to the five roadmap 0.2.5 bullets):

1. **Split remaining god-modules by cohesive state machine.** Prioritize `src/agent-session.ts` (run setup, provider turn, durable suspension, tool round, persistence/ledger), then `src/contracts-core.ts`, `packages/workflows/src/run.ts`, `packages/server/src/handler.ts`, `packages/coding-agent/src/repository.ts`, and `packages/ag-ui/src/acp/agent.ts`. Preserve public barrels and avoid one-implementation interfaces/factories — the 0.1.4 `agents.ts`/`contracts.ts` barrel precedent (plan 016) is the model.
2. **Deduplicate PostgreSQL/SQLite persistence mechanics.** Move proven shared ownership filters, cursor codecs, schema/migration checks, lifecycle/checkpoint shapes, metadata parsing, and search clipping into `packages/session-store-codecs`; leave SQL dialect and query execution in each adapter. No generic ORM/query builder; no new runtime dependency.
3. **Remove quadratic bounded accumulation.** Replace repeated `Buffer.concat` in language framing (`packages/coding-agent/src/language/framing.ts`), tar parsing (`packages/coding-security/src/sandbox-tar.ts`), and CLI capture (`packages/work-tools/src/cli.ts` — already linearized by plan 020 Task 3's chunk-array `collectOutput`; audited and kept) with chunk arrays or bounded ring/stream processing; retain byte caps and abort behavior.
4. **Finish dead-code cleanup.** Remove stale `agent-session` imports/constants, `cache-telemetry` locals, `skill-load` map/scans, and confirmed dead exports; preserve intentionally public exports and documented `ponytail:` ceilings.
5. **Close low-coverage core behavior.** Add focused tests for conversations, artifacts, approval, compaction, and weak conformance-helper branches; test behavior rather than line count; every new branch/loop/parser/security path leaves one runnable regression; package and core thresholds stay above recorded baselines.

## Objectives

- Close the five confirmed maintainability/bounded-performance defects without adding a runtime dependency, a published package, a background service, a second runtime, a generic ORM/query builder, a new interface with a single implementation, or a speculative abstraction. Deletion and consolidation beat new abstraction (roadmap priority rule 4).
- Make every god-module split **compat-preserving**: the public import surface of `@arnilo/prism` and every affected workspace package stays byte-identical in `.d.ts` (the compat baseline records zero breaking deltas); the split files become internal modules re-exported through the existing public barrel so consumer imports do not change. File-size reduction and tree-shaking gain are measured, not assumed.
- Make every persistence-mechanics move **semantics-preserving**: cross-store conformance (the plan 022 `state-concurrency-conformance` harness against memory, Postgres, and SQLite) proves identical behavior before and after the dedup; SQL dialect and query execution stay per-adapter; no shared runtime dependency is added to `session-store-codecs` beyond what the adapters already use.
- Make every `Buffer.concat` replacement **bounds-preserving**: the existing byte caps, overflow-abort, and fail-closed behavior are retained; near-limit benchmarks show linear copying and bounded peak memory; overflow remains fail closed (the 0.2.1 bounded-response-reader invariants are not weakened).
- Make every dead-code removal **evidence-backed**: the existing `scripts/dead-exports.mjs` heuristic scan (plan 015 Task 3) plus a reviewed allow-list drives removal; no public export disappears without migration evidence (roadmap rule: public removals require migration evidence); intentionally-public exports and documented `ponytail:` shortcut ceilings are preserved.
- Make every coverage close **behavior-backed**: one runnable regression per new branch/loop/parser/security path; no line-count padding; package and core thresholds stay above the `scripts/coverage-thresholds.json` recorded baselines (core ≥ 90.53/84.20/90.54; per-package baselines with the 3pp margin).
- Preserve all normal single-process behavior: `npm run build`, `npm run clean`, `npm test`, `npm run test:coverage`, `npm run typecheck`, `npm run sdk:ready`, `npm run lint`/`format`, `npm run release:gate`, `test:postgres`, and `security:threat-suites` keep their current happy paths and exit codes; only internal module boundaries, duplicated persistence mechanics, quadratic accumulators, dead code, and focused tests change.
- Record machine-checkable primitive review, threat model, baseline/measurement evidence, compatibility, package budget, protected-matrix, and release evidence; satisfy the roadmap 0.2.5 acceptance criteria (behavior/exports compatible or migrated; complexity and file-size reductions measured; hot-path benchmarks and tree-shaking do not regress; cross-store conformance proves identical semantics; no ORM/query builder or new runtime dep; near-limit benchmarks show linear copying and bounded peak memory; overflow fail closed; unused sweep clean or explicitly allow-listed; no package API disappears without migration evidence; every new branch/loop/parser/security path leaves one runnable regression; thresholds stay above baselines).

## Non-goals

- No security-blocker work from 0.2.0, no provider/network trust work from 0.2.1, no state-concurrency work from 0.2.2, no build/coverage/release-evidence work from 0.2.3, no package/docs/compatibility-truth work from 0.2.4, no coding-agent readiness from 0.2.6, no ERP readiness from 0.2.7.
- No public API change: `ProviderEvent`, `AgentEvent`, `RunRecord`, `SessionRecord`, `CheckpointRecord`, `AgentSession`, `Agent`, `AgentLoopStrategy`, `ToolEffectStore`, `PolicyEvaluator`, `ArtifactBodyStore`, `WorkflowRun`, server handler request/response shapes, ACP agent contract, `Repository` ops, and every exported symbol stay byte-identical in `.d.ts`. Internal-only splits may move implementation between files but the public barrel re-exports the same names from the same paths.
- No new model provider, delegated agent, enterprise adapter, forge, object store, policy engine, live-canary, package, export subpath, or runtime capability. The publish graph stays 50 packages; no manifest gains or loses a runtime export; no package is added to or removed from the graph.
- No generic ORM, query builder, SQL DSL, or shared SQL execution layer. `session-store-codecs` gains only dependency-free codec/shape/parse helpers (ownership filters, cursor codecs, schema/migration *checks* not *execution*, lifecycle/checkpoint shapes, metadata parsing, search clipping); each adapter keeps its SQL dialect and query execution.
- No new runtime dependency anywhere: core stays dependency-free; `session-store-codecs` stays dependency-free (it already is); the split modules and the `Buffer.concat` replacements use only stdlib (`node:buffer`/`Uint8Array`/`TextEncoder`). No `knip`, no AST-rewrite library, no streaming framework.
- No one-implementation interface or factory introduced to "enable future splitting." Splits land as concrete cohesive modules behind barrels; no speculative `SessionPhase`/`TurnStrategy` interface with a single implementation.
- No behavioral change hidden as a refactor: any change that alters observable behavior (an error code, an event order, a retry count, a concurrency bound) is recorded as a compat-baseline delta with migration evidence and fails the gate unless explicitly approved as an additive fix. 0.2.5 is additive/cleanup-only.
- No removal of `npm run clean`, `npm run build`, `npm test`, the core coverage gate, the `phase*-freeze.test.mjs` legs, the `compat-baseline` gate, the `dead-exports.mjs` scan, or any existing script. Splits/dedup/tests are additive source and `scripts/`-only artifacts.
- No new code-wiki task: `.agents/skills/project-wiki/` does not exist (same as 0.2.0–0.2.4).

## Migration Impact

- **God-module splits (no runtime migration):** `agent-session.ts`, `contracts-core.ts`, `workflows/run.ts`, `server/handler.ts`, `coding-agent/repository.ts`, and `ag-ui/acp/agent.ts` become barrels or re-exporting entry modules over new internal files. Every public import path (`@arnilo/prism`, `@arnilo/prism-workflows`, `@arnilo/prism-server`, `@arnilo/prism-coding-agent`, `@arnilo/prism-ag-ui`) resolves to the same named exports; `.d.ts` is byte-identical (the compat baseline records zero breaking deltas). A consumer that deep-imports an internal path (e.g. `@arnilo/prism/agent-session/provider-turn`) that was never documented gets no guarantee — internal paths are not public; if any such deep import exists in-repo it is updated. Rollback: restoring 0.2.4 restores the monolithic files.
- **Persistence-mechanics dedup (no runtime migration):** Postgres and SQLite adapters import shared codecs/shapes from `@arnilo/prism-session-store-codecs` instead of duplicating them. `session-store-codecs` is already a peer of the adapters (verified in Task 0); if not, the peer is added (a peer pin, not a runtime dep change) and recorded. Persisted shapes (checkpoints, leases, cursors, metadata, search rows) are byte-identical before and after — cross-store conformance proves it. A host that already runs Postgres or SQLite sees no schema migration, no cursor format change, no row shape change. Rollback: restoring 0.2.4 restores the duplicated mechanics.
- **`Buffer.concat` replacements (no runtime migration):** language framing and tar parsing change internal accumulation strategy only; observable behavior (parsed JSON values, tar entries, byte caps, overflow errors) is unchanged and asserted by existing + new tests. Rollback: restoring 0.2.4 restores the quadratic accumulators (and the O(n²) ceiling).
- **Dead-code removal (no runtime migration for internal; migration note for any public removal):** stale imports/constants/locals and confirmed-internal dead exports are removed with no consumer impact. If the reviewed allow-list + `dead-exports.mjs` confirm a *public* export is dead, it is removed only with a `docs/migration.md` `0.2.4 → 0.2.5` note and compat-baseline evidence (0.2.5 is additive-only; any public removal halts the release pending an amendment — expected outcome: zero public removals). Rollback: restoring 0.2.4 restores the dead code.
- **Coverage close (no runtime migration):** new tests are additive; no behavior change. Rollback: restoring 0.2.4 removes the new tests.
- **No runtime consumer migration beyond the version literal:** 0.2.5 ships no `docs/migration.md` runtime section unless a public removal is confirmed (then a `0.2.4 → 0.2.5` note is added). Runtime behavior, persisted shapes, exports, and events are unchanged.

## Package and Performance Budget

- Publish graph remains **50 packages**; no package or export subpath is added or removed. All new artifacts (`scripts/phase25-*.test.mjs`, `scripts/phase25-baseline.json`, `scripts/phase25-freeze-manifest.json`, near-limit probes) live under `scripts/` and are excluded from every tarball. The `session-store-codecs` source grows by the extracted codecs (net repo shrink: the two adapters shrink by roughly the same amount); no `dependencies`/`files`/`exports` change in any published manifest except a possible `session-store-codecs` peer pin already present.
- Runtime dependencies remain unchanged: core stays dependency-free; `session-store-codecs` stays dependency-free; the splits and `Buffer.concat` replacements use only `node:buffer`/`Uint8Array`/`TextEncoder`/stdlib. No `knip`, no AST library, no streaming framework, no ORM/query builder.
- Root and affected package packed/unpacked/file-count growth must remain within `scripts/budgets.json` tolerance. The expected packed delta is neutral-to-negative (code moves between files inside the same packages; `session-store-codecs` grows, the two adapters shrink by a similar amount; `agent-session.ts` shrinks but the new internal files add — net zero within a package). Re-baselined only if measured outside tolerance, with a dated `$comment` per the recorded release convention.
- Hot-path performance: the `Buffer.concat` replacements **improve** near-limit framing/tar behavior (quadratic → linear); the god-module splits and persistence dedup are not on the provider hot path (provider turn stays in `agent-session` → `provider-turn.ts`, same code, same cost). The frozen p95 ceilings in `scripts/budgets.json` and `benchmark-0.1.0.json` must not regress; a focused near-limit probe asserts linear copying and bounded peak memory for framing and tar. Tree-shaking: the `agent-session.ts`/`contracts-core.ts` split is measured (bundle-size delta or export-reach analysis) — improvement expected, regression fails the gate.
- Coverage: core stays ≥ 90.53/84.20/90.54; per-package thresholds stay above `scripts/coverage-thresholds.json` baselines with the 3pp margin. Adding focused tests only raises coverage; the threshold gate is a floor, not a ceiling.
