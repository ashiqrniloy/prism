## 0.13.0 release path

Run these plans in step order, one at a time. Each starts when the one before it is complete; nothing else is needed to know what comes next. Step order is number order except plans 188–196 (added 2026-10-17: memory research alignment, the coding-tool, skills, and delegation fixes, the two web-tools parts, the context-rot defenses, then roadmap Phase 18's decision calls and Liquid provider), which run between 183 and 184 (plan 188.1, added 2026-10-19, runs right after 188; plans 188.2–188.6, added 2026-10-19 for the memory lifecycle — scope hierarchy, session consolidation, retention, delivery tiers, and lifecycle evaluation — run after 188.1; plan 188.7 follows 188.6's partial Task 6 campaign without waiting for that task's completion, fixes the evaluation findings and runs mandatory paid acceptance; plan 188.8, added 2026-10-22, follows 188.7's partial Task 8 campaign to fix the localized fabric delivery and agentic-recall causes of F13 and runs a paid held-out comparison; plan 188.9, added 2026-10-22 after 188.8's post-acceptance investigation, makes the fabric general-purpose (evidence-sized delivery, agentic tool fixes, exchange archive, domain-neutral extractor, product-path benchmark ingestion, faster evaluation) with a paid screen and held-out acceptance; plan 188.10, added 2026-10-23 after 188.9's held-out acceptance on the owner's decision that multi-session recall is required for 0.13.0, follows 188.9; plan 188.11, added 2026-10-24 after 188.10 met its target, follows 188.10 and ends the 188.x sequence before 189 because it reduces the memory export surface that 185 freezes); plans 197–201 (added 2026-10-19: the eval-system review's correctness fixes, statistics, judges, agentic evals, and production wiring) run after 196 and before 184; plan 202, added 2026-10-24 on the owner decision that memory robustness ships in 0.13.0, follows 201 and runs before 184 because it reuses 198–200 statistics, judges and datasets and must land before 185 freezes the surface. Plans 203–204 (owner decisions 2026-10-24 and 2026-10-25: OpenRouter, and OpenAI Codex via Sign in with ChatGPT, each thoroughly live-tested with prompt-cache parity against an established harness) run as steps N1–N2, in that order, **right after plan 194 completes** (Tasks 1–5 done, 6–7 in progress). They come before 188.11 (not started), before 197, and before plan 185 freezes the surface. Each one feeds its routes' overflow evidence into 194's landed `context_overflow` handling directly. Plans 205 (Command Code) and 206 (Ollama Cloud) are **not on the 0.13.0 path**: on 2026-10-25 the owner deferred both providers to the first release after 0.13.0, so the plans keep their research and task breakdown and run then — after 187 publishes, not before the freeze. Live benchmarks and release acceptance stay on Hyper and OpenCode Go. Every earlier Phase 11 plan (174–180) is complete or closed, and its open tasks were moved into this list on 2026-10-16. Plans 097, 107, and 133 are older `planned` rows that are not on the 0.13.0 path.
