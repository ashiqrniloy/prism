**Wall time.** The screen ran about 100 s per task, so a 100-task job takes about 3 h. The 60 jobs at concurrency 6 take about 30–35 h, and 2 repetitions about 60–70 h. With `mem0` there are 72 jobs: about 36–42 h.

**Power.** The screen's STM-only → STM+WM interval was ±0.09 at N = 35, with about 4.2 dependency checks per session, which gives a per-session SD of about 0.27. With about 10 or more `after` dependency checks per session, and if within-session noise dominates, the SD falls to about 0.17.
