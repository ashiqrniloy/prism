# Phase 16 Part A — Workflow engine port, checkpoint and lease services, and the prism-core runtime retirement

## Objectives

- Review every contract Phase 16 touches before code starts: the 0.12 engine's module-by-module fate, the `checkpoints` and `leases` service contracts and who consumes them, the kernel's own use of `CheckpointStore` for durable run state, how a workflow reaches services and the host port from outside an agent's setup, how `workflow.*` events reach a parent session, and how `fanOut` learns a profile's cap.
- Create `@arnilo/prism-workflows` as a native package and port the 0.12 graph engine into it: definitions, revision hash, limits, Kahn and superstep scheduling, the kept node kinds, checkpoints, suspend/resume, replay, graph export, and the run overlay.
- Make checkpoints and leases (gap G6) service contracts owned by `@arnilo/prism-workflows`, with in-memory defaults and conformance suites, implemented by `@arnilo/prism-store-sqlite` and `@arnilo/prism-store-postgres`.
- Delete the kernel copies (`src/checkpoints.ts`, `src/leases.ts`, the `CheckpointStore`/`LeaseStore` contracts) and every 0.12 consumer path that depends on them, as the review decides.
- Move `@arnilo/prism-core/governance/observability` into `@arnilo/prism-observability`, and delete `@arnilo/prism-core/runtime/workflows` with every consumer migrated or deleted.

## Expected Outcome

- `import workflows, { defineWorkflow, runWorkflow, resumeWorkflow, replayWorkflow, functionNode, conditionalNode, routeNode, joinNode, loopNode, workflowNode, workflowGraphToMermaid } from "@arnilo/prism-workflows"` works, and the ported engine's tests pass in `packages/integrations/workflows`.
- `@arnilo/prism-workflows` exports the `CheckpointStore` and `LeaseStore` service contracts, `createMemoryCheckpointStore`/`createMemoryLeaseStore`, and `checkpointConformance`/`leaseConformance` from `@arnilo/prism-workflows/testing`.
- Listing `@arnilo/prism-store-sqlite` or `@arnilo/prism-store-postgres` provides the `checkpoints` and `leases` services, and both pass the conformance suites.
- `rg -n "CheckpointStore|LeaseStore|createMemoryCheckpointStore|createMemoryLeaseStore" src` finds nothing. The root export freeze and `scripts/compat-baseline/arnilo__prism.txt` record the removals.
- `@arnilo/prism-core` no longer has the `./runtime/workflows` or `./governance/observability` subpaths. Every example, script, test, and package that used them is migrated or deleted, as Task 1 records.

This plan implements roadmap **Phase 16 — Graph workflows across agents**, Part A. Part B (plan 169) ships the agent orchestration surface on top of this engine: the parent session and `workflow.*` events, `agentNode` with `parent` links and `worktree`, `gateNode`, `humanGate`, `fanOut` with profile pacing, the merged `stream()`/`steer(nodeId)`/`abort()`, resume after a kill, `workflowCommand`, `workflowLoop`, origin-aware observability, `examples/build-workflow.ts`, `examples/workflow-loop.ts`, and the Phase 16 Done record. **Task 1 is the phase review for both parts.** Part B opens with an entry check. The review has one known roadmap conflict to resolve first: the kernel's durable run state (`AgentConfig.runState`, `src/agent-run-state.ts:182,244`) is built on the same `CheckpointStore` contract that Phase 16 says to delete from the kernel. Depends on plans 163–167 (Phases 13–15) and plan 160 (Phase 9 `observability`). This plan does not bump versions, publish, deprecate on npm, or edit released `/docs`.
