# Release 0.1.4 — God-module split (compat-preserving)

Roadmap phase: 0.1.x line, milestone **0.1.4 — God-module split (compat-preserving)** (`roadmap.md`, "0.1.4 — God-module split (compat-preserving)"; architectural problem #2 and "Refactoring needs").
Baseline: `@arnilo/prism` **0.1.3** (plan 015 exit gate green; `scripts/phase15-baseline.json`; 49 publishable manifests; `npm audit --audit-level=moderate` 0; compat baseline additive-only at 0.1.3).
Target: `@arnilo/prism` **0.1.4** (compat-preserving internal refactor; split `src/agents.ts` and `src/contracts.ts` by concern behind barrel re-exports; no public-export removals, renames, or signature changes; no new packages, no new runtime dependencies). Plus (scope amendment 2026-08-10, Tasks 4-5): **Chrome DevTools Protocol (CDP) agentic capabilities for `@arnilo/prism-browser`** — additive to the `@arnilo/prism-browser` package only, riding the existing optional `playwright-core` peer dependency; the root `@arnilo/prism` surface stays identical.
Prerequisite: 0.1.3 exit gate passed; `docs/public-contracts.md` 0.1.x contract surface frozen; compat baseline green at 0.1.3.

0.1.4 is **a compat-preserving internal reorganization plus an additive `@arnilo/prism-browser` CDP feature**, not a breaking cut (versioning policy: the 0.1.4 pulled-forward module stays compat-preserving behind barrel re-exports; the documented breaking cut is **0.1.5**). Roadmap priority rule 5 applies: the split ships behind barrels so the compat baseline stays green, and the deprecated-option removal is explicitly out of scope (0.1.5). Every 0.1.4 change keeps the **root** `@arnilo/prism` public declaration surface **identical** (zero added, zero removed, zero changed) vs the 0.1.3 baseline — the only root delta is the version literal. The browser CDP feature extends `@arnilo/prism-browser` additively (new tools/types/limits + optional members on two existing structural interfaces); `@arnilo/prism-browser`'s own baseline is regenerated with those documented deltas (deviation #2), which does not touch the root package's surface.

## Why the split is provably compat-preserving

`scripts/release-gates.mjs` computes the compat surface as the **union of every `.d.ts` under the package `dist/`** (`extractDeclaredSurface`): it parses each file's local declarations (`locals`), named re-exports (`named`), and star re-exports (`stars`); visits star targets depth-first; then adds named re-exports (first-wins) and local declarations (override). `diffSurface` flags a name as `changed` only when `current.get(name) !== baselineSignature`.

Consequence for this plan: a directly-declared symbol (e.g. `export interface AgentRunState {…}`) keeps the **same signature bytes** regardless of which `dist/*.d.ts` file declares it, because (a) star re-exports resolve transitively to the declaration's home file and (b) `locals` override re-export statements. Therefore moving `AgentRunState` from `contracts.ts` to `contracts-run-state.ts` and adding `export * from "./contracts-run-state.js"` to the `contracts.ts` barrel leaves the union surface byte-identical — `index.ts`'s `export type * from "./contracts.js"` (line 128) still resolves every name to the same declaration text. The same holds for `agents.ts`'s four public exports as long as they stay reachable through the barrel. This is the mechanism that lets 0.1.4 refactor two ~2,550-line god-modules with **zero compat-baseline deltas**.

## Objectives

- Split `src/contracts.ts` (2,549 lines, ~295 exports) into **core contracts**, **run-state**, and **protocol-payload** modules behind a `src/contracts.ts` barrel that re-exports all three, so `src/index.ts`'s `export type * from "./contracts.js"` (line 128) is unchanged and every public contract name resolves to the same declaration.
- Split `src/agents.ts` (2,576 lines, 4 public exports) into **run-lifecycle**, **approval/pending-decisions**, **tool dispatch**, and **fingerprint** modules behind a `src/agents.ts` barrel, reusing the already-split `src/agent-run-state.ts` (fingerprint + run-state persistence) and `src/agent-run-lifecycle.ts` (run-lifecycle contract) and moving the remaining free functions + the `RuntimeAgentSession`/`EventSubscriber` classes into sibling modules so `agents.ts` becomes a barrel that still exports `createAgent`, `createAgentSession`, `resumeAgentRun`, `resumeAgentRunStream`.
- **Measure** the tree-shaking improvement the roadmap requires (zero-dependency script: `dist/agents.js` + `dist/contracts.js` byte sizes, `dist/*.js` module count, and a static-import reachability count from a minimal consumer entrypoint, recorded before/after in `scripts/phase16-baseline.json`).
- **Extend `@arnilo/prism-browser` with Chrome DevTools Protocol agentic capabilities** (scope amendment 2026-08-10): a CDP session layer over playwright-core's existing CDP transport (host-supplied Chromium browser), `browser_evaluate` (bounded page-context JS), `browser_observe` (bounded console + network observation), raw `css`/`xpath` act targets, and CDP-backed `block_urls`/`unblock_urls`/`throttle`/`emulate` act actions — all behind the existing execution-policy, egress, and limits model, additive to the `@arnilo/prism-browser` surface only.
- Keep `npm run sdk:ready` green, `npm test` green, `npm audit --audit-level=moderate` 0, and the compat baseline at **zero deltas** (additive-only is insufficient — this release targets identical surface, recorded as zero added/removed/changed in `scripts/compat-baseline/arnilo__prism.txt`).

## Non-goals

- Removing or renaming any public export, or changing any public declaration signature — that is the **0.1.5** breaking cut with `docs/migration.md` removed-symbols list.
- Changing any runtime behavior, algorithm, or test expectation — the split is a pure move; the existing `npm test` suite (core 1,425/1,425 + gates at 0.1.3) must pass unchanged.
- New packages, new subpaths, new public re-exports, or new runtime/dev dependencies (a bundler devDep for tree-shake measurement is explicitly rejected — see Task 3). The CDP feature adds **no** dependencies: it rides playwright-core's existing `newBrowserCDPSession()`/`newCDPSession(page)` API (already the optional peer dep of `@arnilo/prism-browser`) and never launches or downloads browsers (host-supplied browser model unchanged).
- CDP domains beyond the agentic allowlist: cookies (Network.getCookies/setCookie/clearBrowserCookies — credential-sensitive, needs its own policy/redaction design), tracing/performance profiles, IndexedDB, and worker/auto-attach debugging are explicitly **out of scope for 0.1.4** (deferred list in Further Actions).
- Splitting the `RuntimeAgentSession` class across files (TypeScript classes cannot be split cleanly; the class moves whole into `agent-session.ts`). Decomposing the class via composition/mixins is a behavior change and out of scope.
- A primitive-review task — this plan adds no editor mode, language mode, JS package, extension point, or reusable public capability (create-plan skill rule 6); it is an internal refactor of already-public surface behind barrels.
- A final code-wiki task — `.agents/skills/project-wiki/` does not exist (create-plan skill rule 8).
- Umbrella provider membership, durable ACP store, deprecated-option removal, prompt-cache telemetry — 0.1.5/0.1.6/0.1.7/0.2.0.

## Expected Outcome

- `src/contracts.ts` is a barrel: `export * from "./contracts-core.js"; export * from "./contracts-run-state.js"; export * from "./contracts-protocol.js";` (plus the existing alias re-exports for `identity.js`/`persistence-lifecycle.js` at the file tail, kept in place). The three new files hold the moved declarations verbatim (same declaration text, same names).
- `src/agents.ts` is a barrel: `export * from "./agent-session.js"; export * from "./agent-approval.js"; export * from "./agent-tool-dispatch.js"; export * from "./agent-resume.js";` (reusing `agent-run-state.ts`/`agent-run-lifecycle.ts` which are already split and already re-exported through `index.ts`). The four public exports stay reachable; `RuntimeAgentSession`/`EventSubscriber` move whole into `agent-session.ts`.
- `scripts/phase16-baseline.json` records the measured tree-shaking improvement: `dist/agents.js` and `dist/contracts.js` shrink (bytes), `dist/*.js` module count rises (more, smaller files), and the static-import reachability from a minimal `createAgent`-only consumer entry does not increase (the split lets a future bundler drop unused approval/tool-dispatch/run-state modules).
- `scripts/compat-baseline/arnilo__prism.txt` regenerated at 0.1.4 with **zero** added/removed/changed deltas vs the 0.1.3 baseline (only the version literal moves). `scripts/compat-baseline/arnilo__prism-browser.txt` regenerated with the documented CDP additions (new exports + optional-member interface extensions; no removals; deviation #2). `npm run sdk:ready` rc=0; `npm test` green; `npm audit --audit-level=moderate` 0; publish dry-run 49/49 byte-deterministic (twice).
- `docs/migration.md` carries a `0.1.3 → 0.1.4` section stating the internal file reorganization, the additive `@arnilo/prism-browser` CDP surface, and that the root public surface is unchanged (no migration step); `docs/index.md` current line → 0.1.4 and its browser-automation line names the CDP tools.
