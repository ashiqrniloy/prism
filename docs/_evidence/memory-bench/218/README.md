# Plan 218 evidence (gate M-2) and plan 218.1's Compact-Bench readings

Evidence holds ids, counts, scores and hashes only; no transcript, record, session or summary text.

| File | What it is |
|---|---|
| `gates/owner-gate-m2.json` | The owner's record for gate M-2 (plan 218 Task 6) and the sections plan 218.1 Task 3 adds: `compactBenchWmProbe` (the Step 1 probe rule, its approval, the relaunch, and `reprobe`, the post-218.2 re-probe approved on 2026-11-15, launched on 2026-11-16, and its `rebinds`) and, once the owner approves Step 2, `compactBenchScreen` (the screen rule and branch). A changed rule is a refusal, never a re-approval. |
| `wm-probes.json` | Plan 218 Task 5's offline WM mechanism probes (regenerated by plan 218.2): rows M2–M4 read from it, and the paid run refuses to start unless every WM probe reads `works`. |
| `compact-bench-wm-probe.json` | Plan 218.1 Task 3 Step 1, the WM engagement probe on 30 Compact-Bench retention sessions (counts and cost; nothing scored). It holds two readings: `pre-218.2` (2026-11-13, product `e7e100f1…`: 30 of 30 engaged, Branch A; it cannot start Step 2) and `post-218.2` (2026-11-16, product `c225f065…`: 30 of 30 engaged, Branch A), which selects the branch for Step 2 on the product it was read on, or, under the owner rebind in `reprobe.rebinds`, on any product whose memory packages still hash as at launch (kernel `src/` edits waived). |
| `compact-bench-wm-probe.stop-2026-11-13.json` | The first full probe run, stopped on its failure cap by a harness settle deadline (4 of 8 sessions); kept as run. |
| `compact-bench-screen.json` | Plan 218.1 Task 3 Step 2, the retention screen (written by `external/compact-bench/screen.mjs --score`): per arm and reference, retention per session, S characters, the paired estimates and intervals, the verdict under the approved `SCREEN_RULE`, and M5 (Branch A). Absent until the screen runs. |
| `equivalence.json` | Plan 218's cache-stability equivalence attestation (`prefix-probe.mjs --equivalence`, kind `202-cache-stability-equivalence`): `identical`. |
| `runs/` | Gate M-2's run reports, execution manifests and preflights. Reports from before plan 218.2 move to `runs/superseded-pre-218.2/` when plan 218 Task 6 rebuilds the manifest. |
