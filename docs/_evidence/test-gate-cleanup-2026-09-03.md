## 5. Pre-existing issues surfaced by full verification (fixed in this task)

1. **Stale coverage baseline (web-tools).** `scripts/coverage-thresholds.json`
   pinned web-tools lines at 87.16, recorded at the 0.4.0 consolidation.
   Plan 056's later `uploads.ts` TOCTOU hardening (+16 defensive lines, mostly
   error paths) dropped measured coverage to a rock-stable 87.02 (3 identical
   runs), failing the gate. Re-baselined per the documented plan-023 convention
   (threshold = measured − 3 pp margin): lines 87.16 → 84.02, branches/functions
   refreshed (73.43 / 90.58). The gate still trips on any regression below the
   margined floor. The implementation-review coverage table's 87.16 web-tools
   row matched the threshold byte-for-byte while every other row matched
   current measurement — it was copied from the threshold file, not measured.
2. **wiki_search foreign-collection poisoning (`qmd` client).**
   `QmdClient.search` ran `qmd search --json` against qmd's **global** index
   (qmd 2.8.3's CLI has no collection scoping) and mapped every hit
   verbatim — a foreign collection document (verified via a probe collection)
   outranked the workspace's own compiled entity, failing
   `prism-wiki E2E codebase lifecycle` and the wiki tools suite. A second
   defect: an empty array was returned as-is, so the intended in-repo catalog
   fallback (catch-only) never ran when qmd was installed with an empty or
   wedged collection (`qmd collection add` refuses re-registration of an
   existing name, so a collection pointing at a deleted fixture stays `Files: 0`
   forever — observed `prism-wiki` collection). Fixed in
   `packages/memory/src/wiki/search/qmd-client.ts`: hits are filtered to
   non-empty, non-`qmd://` files (foreign collections surface as `qmd://` URIs)
   and empty/foreign-only answers fall back to the catalog scan. Memory wiki
   suites: 39/39 green with the poisoned global index still present (the fix is
   index-state independent). Probe artifacts removed; the wedged `prism-wiki`
   collection was left in place (harmless once the fallback is the empty-index
   path).
3. **Format hygiene.** 6 files failed `biome format .`: `packages/office/src/documents/patch.ts`,
   `packages/office/src/documents/__tests__/patch.test.ts`,
   `scripts/phase27-dr.test.mjs` (pre-existing, plan 056 era) and
   `scripts/import-hygiene.test.mjs`, `scripts/phase16-tree-shake.mjs`,
   `scripts/phase26-freeze.test.mjs` (plan 057 edits). All formatted; diffs are
   whitespace-only. `biome format .` now exits 0.
